# 🛒 ProductIQ eCommerce Analytics

An end-to-end e-commerce analytics project analyzing 150,000+ interactions. Features data cleaning in Python, custom DAX metrics in Power BI, and interactive deployment via Streamlit.

## 📌 Features
- **Data Pipeline:** Processed raw `events.csv` into `productiq_clean.csv` using Python Pandas.
- **Power BI Dashboard:** Includes custom DAX metrics, revenue heatmaps, and interactive slicers (`.pbix` included).
- **Interactive Streamlit App:** Deployed web interface allowing public access without software dependencies.
